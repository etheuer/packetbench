# Redesign notes

## World chosen

Print shop + federal file clerk. Cool sage paper, one oxide-red stamp, hairline rules, numbered exhibits, hanging-folder object in the first viewport. Self-hosted Geist. Dark mode through `prefers-color-scheme`. Dials: VARIANCE 6 / MOTION 3 / DENSITY 4.

Offer chrome is generic and data-driven (`buyer`, `packet`, `turnaround`, `price`, short brand). No desk-specific markup in the template.

## What was stolen from each reference

**Unbounce B2B examples.** One goal per page. No catalog nav. Problem in the headline. CTA visible without scroll. Short intake. Adult B2B, not startup-cute. Visual of the work (the file), not a gradient.

**Front customer-service page.** Pain in the hero. A concrete object of the job (folder + ruled sheet) instead of a blob or a SaaS screenshot.

**Directive PPC page.** Professional-services trust: how the work runs, what is in, what is outside. Process as a rail, not product theater. Repeat one CTA.

**2026 B2B pattern (Instapage / Flowtrix / Popupsmart).** Benefit/failure headline, CTA above the fold, short form, proof next to the ask, same CTA repeated, mobile-first. Proof is file contents + turnaround + what we will not do.

## What was refused

- Fake logos, quotes, ratings, case-study percents
- Packaged-dollar value stacks
- Packetbench on offer pages
- Google Fonts, Inter, Fraunces, npm, deploy
- AI-purple, three identical icon cards
- SaaS dashboard mockups
- "Sit-Beside", DFY, "Buy this if"
- Em-dashes and en-dashes in page copy
- Rewriting LANDING or offer IDs for this pass
